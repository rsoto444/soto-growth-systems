# sotogrowthsystems.com

The website for Soto Growth Systems, owned by Rich Soto.

- **The site:** Next.js in `website/`, deployed by Vercel (project soto-growth-systems, Root Directory `website`) from the `main` branch.
- **Pages:** the 15 pages moved word for word from WordPress live in `website/lib/wp-pages.json`, generated by `code/import_wordpress.py` from the WordPress export. Every approved text change is listed in that script.
- **Leads:** the Contact page form posts to `/api/lead/`, which forwards to the GoHighLevel inbound webhook (`LEAD_WEBHOOK_URL`, set in Vercel and `website/.env.local`, never in code).
- **Business facts and decisions:** `CLAUDE.md`, section "My setup".
- **SEO commands:** the Claude Code commands in `.claude/commands/` (/audit, /keyword-research, /service-page, /blog-post, /seo-optimization, /publish) come from the SEO Agent toolkit in rsoto444/SGS.

Run it locally: `cd website && npm install && npm run dev`, then open http://localhost:3000.
